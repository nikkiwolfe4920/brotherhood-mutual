Partner Integration

Pull your matched-organization and opportunity-funnel data straight from the Partner Console into your own CRM or reporting tools using the snippet below.

API request

Copy this into your terminal, server, or integration tool.

cURL 
curl -X GET "https://api.brotherhoodmutual.com/partner/v1/highpoint/opportunities" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Accept: application/json"

Replace YOUR_API_KEY with the API key issued to Highpoint Roofing & Restoration. Need a key or lost yours? Contact your Brotherhood partnership manager.

Sample response

What each matched opportunity looks like in the response payload.

JSON 
{
  "opportunities": [
    {
      "organization": "Grace Fellowship",
      "size_band": "Large ministry",
      "region": "Midwest",
      "stage": "Recommended",
      "match_quality": "High",
      "agent": "Alan",
      "last_updated": "2026-08-11"
    }
  ]
}
This API only returns the fields permitted under Highpoint's partner agreement — the same governed subset shown in the Partner Console, never Brotherhood's full customer record.
